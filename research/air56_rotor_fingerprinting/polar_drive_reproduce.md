# Повторение опыта по управлению через силовые обмотки

Из рабочего дерева mic_theory запустить в PowerShell на исследовательском интерпретаторе с NumPy, SciPy, scikit-fem, Numba и Matplotlib.

```powershell
$python = 'C:/mic_theory/.venv/Scripts/python.exe'
& $python research/air56_rotor_fingerprinting/polar_drive.py --out C:/mic_air56_marker_results/polar_motion --verify
```

Для нового расчёта указать пустой каталог и опустить `--verify`. Параметр `--archive` указывает каталог с исходной FEM-картой штатной машины `family_screen/stock.npz` и движущимися картами `pwm_slopes_18` предыдущей серии. Новая серия выполняет локальные физические решатели, сравнивает шумовые испытания и формирует контрольные суммы результатов. Численные метрики предпочтительны для сравнения разных версий библиотек. SHA-256 проверяет целостность уже сохранённого архива.

Отдельный прогон основной серии при 0,8 Н·м и скосе в один шаг:

```powershell
& $python tools/score_air56_direct_drive.py --out C:/mic_air56_marker_results/repeat_one_case --group rated_skew
```

Результат включает 32 численные траектории в таблице и подробные временные ряды первой и последней. У столбцов `trace` порядок следующий: время, истинный механический угол, его оценка, истинная и оценённая скорости, задание угла и скорости, интегральная составляющая регулятора, мгновенный модуль тока, RMS модуля тока за блок и пиковый модуль за блок. Единицы СИ. Истинные значения нужны для проверки. Углы развёрнуты с момента включения.

Копии сводных чисел входят в репозиторий. В таблице привода каждая строка объединяет 32 пуска. В таблице полевой модели каждая строка описывает одну фактически рассчитанную траекторию. Для пересчёта геометрии нужен каталог исходных CAD-файлов из внешнего архива `family_screen/cad_verified`. Генератор принимает путь к интерпретатору FreeCAD через `--cad-python`.
