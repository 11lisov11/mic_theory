Для каждого первоначального этапа сохранены `results.json`, `analysis.json`,
`aggregate.csv` и `results_report.md`. В подтверждающем этапе также сохранён
полный сравнительный рисунок. Файл `results.json` содержит индивидуальные
показатели всех расчётных случаев и временные зависимости для первого seed.

Данные этапов сохранены без исправления исторических записей. Показатели статьи
относятся к заранее заданному основному сравнению `confidence_feedback` с
`fixed_reference` в режимах `parameter_drift` и `composite`. Остальные алгоритмы
и режимы доступны для анализа в этих же исходных файлах.

Дополнительная проверка ковариации использует те же 20 реализаций воздействий,
что и подтверждающий этап; её протокол и анализ находятся в отдельном каталоге.
