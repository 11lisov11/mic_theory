# Поверхностная межлистовая перемычка на 18-пазовом роторе АИР56В2

## Сопоставляемые модели

В обоих вариантах использована геометрия 24/18 из [исследования раскрытий](air56_18_slot_openings.md). Диаметр ротора составляет 48 мм, зазор 0,25 мм, длина пакета 54 мм. Значения описывают профиль из публикации, геометрия ротора стенда пока не установлена.

- Поверхностная метка задаётся одним локальным межлистовым контуром в середине пакета закрытопазового ротора. Использован двухлистовой 3D-образец из [предыдущего FEM-расчёта](air56_slot_current_tracking.md) с двумя контактами по 100 мкОм, шириной пятна 0,28 мм и разносом пятен 1,56 мм. Размер локальной рабочей области составляет 0,64 × 2,26 мм в плоскости листа. Перенос поля рассчитан внутри зубца на глубине 0,43 мм. Стальная перемычка над каждым стержнем остаётся частью исходной геометрии.
- Вариант с переменными раскрытиями использует сохранённые проверенные карты для ширин 0,65–1,50 мм и глубины 0,5 мм. Для сопоставления проверены геометрия, частота и контрольные суммы входных карт.

Для каждого уровня сетки 3D-задача решена с изолированными листами и с контактами. Разность импедансов преобразована в локальный тензор по двум компонентам поля. Поле в зубце рассчитано на закрытопазовом роторе в 112 положениях на 180° для каждой из двух 2D-сеток. Узлы контрольной карты сдвинуты на половину углового интервала. Тензор перенесён на клеммы как локальная поправка первого порядка, пропорциональная произведению двух компонент поля. Период полуоборота проверен сравнением поля в точках, разделённых 180°.

При скосе на один шаг (20°) импеданс закрытой клетки усреднён по 64 сечениям. Локальная поправка привязана к середине пакета. Импеданс ротора с переменными раскрытиями усреднён целиком, поскольку его геометрия повторяется вдоль пакета с осевым поворотом. Расчёт не включает взаимодействие осевых токов и торцевые эффекты.

## Оценка скорости

Для обоих вариантов использованы проба 500 Гц и 1 В, окна 1,2 и 4,8 с, шум фазоров 0,3 и 3 мА, а также скорости 0, ±1,2 и ±2,7 об/мин. На каждый знак и модуль скорости приходится 24 парных прогона с общими начальными углами и шумом. На покой приходится по 24 прогона. Калибровка учитывает геометрию и скос. Прогон считается успешным при подтверждённом движении и верном определении знака, оба решения требуют модельной уверенности от 95%. Ошибка модуля считается для прогонов с подтверждённым движением. Шаг сетки оценки скорости 0,5 об/мин.

## Результаты

| Пиковый контраст угловой составляющей | Без скоса | Скос 1 шаг |
|---|---:|---:|
| Закрытый ротор с локальным контуром | 3,73 мкА/В | 0,248 нА/В |
| Добавка только от контура | 0,248 нА/В | 0,248 нА/В |
| Переменные раскрытия | 995 мкА/В | 953 мкА/В |

Без скоса почти весь угловой отклик ротора с контуром даёт закрытая клетка. Скос подавляет рисунок закрытых пазов. Сохранившаяся добавка контура примерно в четыре миллиона раз меньше контраста переменных раскрытий при обоих скосах. При переходе между сетками относительное расхождение локального 3D-тензора составляет 3,7%, а максимальное расхождение угловой составляющей перенесённой токовой добавки составляет около 9,5%.

Число успешных прогонов из 48 при шуме 0,3 мА. В каждой группе по 24 прогона на каждое направление.

| Скорость, об/мин | Окно | Перемычка, скос 0 | Перемычка, скос 1 | Раскрытия, скос 0 | Раскрытия, скос 1 |
|---:|---:|---:|---:|---:|---:|
| ±1,2 | 1,2 с | 0 | 0 | 0 | 0 |
| ±2,7 | 1,2 с | 0 | 0 | 16 | 2 |
| ±1,2 | 4,8 с | 0 | 0 | 48 | 48 |
| ±2,7 | 4,8 с | 0 | 0 | 48 | 48 |

С перемычкой движение ни разу не было подтверждено, поэтому показателей ошибки скорости для неё нет. Для переменных раскрытий при 0,3 мА и окне 4,8 с все допущенные оценки модуля составили 1,0 и 2,5 об/мин при истинных 1,2 и 2,7 об/мин соответственно. В коротком окне при ±2,7 об/мин и одном шаге скоса движение подтвердилось во всех прогонах с P95 ошибки модуля 0,7 об/мин. Верный знак получен в двух прогонах.

При 3 мА у перемычки также ноль подтверждений движения. У переменных раскрытий окно 4,8 с дало по 23/48 успешных прогонов на ±2,7 об/мин при обоих скосах. На ±1,2 об/мин и при любом окне, а также на ±2,7 об/мин при окне 1,2 с успешных прогонов нет.

## Воспроизведение

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
python tools/run_air56_18_surface_bridge.py `
  --closed-map C:/mic_air56_marker_results/skew_audit_v1/verified/article18-impedance.npz `
  --openings-map C:/mic_air56_marker_results/slot18_openings_verified/modulated_impedance.npz `
  --out C:/mic_air56_marker_results/slot18_surface_bridge_reproduction
```

В результатах сохраняются карты импеданса, поля переноса, добавка локального контура и строки всех 1 920 прогонов. Стенд в эксперименте не использовался.
