# Отклик двух роторов АИР56В2 при импульсном питании под нагрузкой

## Рабочая точка и импульсы

Использованы два ротора 24/18 из [нелинейного FEM-сравнения](air56_loaded_contrast.md). У одного меняется ширина стержней под закрытой сталью. У второго меняется ширина раскрытий. Рабочая точка соответствует примерно 0,8 Н·м и частоте скольжения 5 Гц. Возбуждение и считывание используют штатные обмотки статора. Ток рабочего поля задан прежними амплитудами 1,449 и 1,366 А. Для обеих знаковых скоростей направление рабочего поля фиксировано.

Подаётся последовательность ступеней напряжения двухуровневого трёхфазного инвертора с шиной 322 В, центрально-симметричной модуляцией на частоте около 16 кГц и мёртвым временем 1,35 мкс. Длительности округлены до тактов таймера 170 МГц, полный период составляет 10 624 такта. В мёртвое время напряжение плеча определяется знаком последнего рассчитанного тока с учётом рабочего тока. Команда включает компенсацию мёртвого времени по знаку задания основного тока. Частота и мёртвое время взяты из архива `drive_parameters.h`, значение шины из архивной записи калибровки. Модель использует идеальные уровни ключей. Реальные падения, задержки переключения IPM и действующие сигналы `CCR` по скорости не измерялись. [Документация ST по плате](https://www.st.com/resource/en/data_brief/steval-ipm15b.pdf) · [Комплементарный ШИМ и мёртвое время STM32](https://www.st.com/content/st_com/en/technical-documents/an4277-how-to-use-pwm-shutdown-for-motor-control-and-digital-power-conversion-on-stm32-mcus-stmicroelectronics.html).

## Переходная FEM

В каждом сечении нелинейное рабочее поле получено по кривой `H(B)` с токами клетки. Для переходной карты по кривой `H(B)` строятся дифференциальные матрицы на 12 фазах полупериода. Во время интегрирования они интерполируются по фазе рабочего поля. К цепи статора подключены сопротивление и потокосцепление FEM. В клетке сохраняется нулевой суммарный осевой ток при идеальных кольцах. Переходные переменные несут историю токов в клетке от одного фронта до следующего. Поле в угловой карте интегрируется в проекции FEM ранга до 40 на сечение. При скосе пять поперечных сечений связаны одним током статора и усредняются по потокосцеплению. В контрольном положении также применены девять сечений. Межсекционные токи отсутствуют.

На контрольном угле каждого ротора короткие записи с фронтами ШИМ повторно решаются на полной FEM-сетке с нелинейным `H(B)` на каждом временном шаге. Прямое решение начинается в той же нелинейной рабочей точке и получает те же ступени напряжения. Проверка сравнивает ток с пробой относительно отдельного расчёта без пробы. Такой парный подход используется и в переходных исследованиях дифференциальной индуктивности. [Schepe и Ponick, 2023](https://research.uni-hannover.de/en/publications/evaluation-of-an-induction-machines-differential-high-frequency-i/).

Для каждого скоса карта содержит 36 положений на полуобороте на каждой из двух плотностей сетки. Поворотная симметрия используется для построения FEM-матриц за пределами сектора 60°. На каждом угле последовательность плеч рассчитывается заново для заданных осей пробы. Для каждой карты выполняются три прогона по 0,4 с. Первый без пробы, два с пробой 100 Гц и 1 В по α и β. По среднему току каждого периода ШИМ во второй половине записи выделяются 100 Гц и боковые полосы, отстоящие на кратные 10 Гц. Токовая матрица собирается в шести фазах рабочего поля. Это расчёт синхронной демодуляции средних токов периода. Задержки и квантование АЦП в модели отсутствуют.

Наблюдатель считывает скорость из двух угловых карт, построенных на разных сетках, с угловым сдвигом контрольных точек 2,5°. Механическое движение при оценке задаётся интерполяцией независимой карты по углу. Внутри переходного FEM-прогона угол ротора фиксирован. Полная совместная сборка с движущейся сеткой и многосекционный нелинейный расчёт всей траектории остаются вне модели. Окно оценки 3,6 с, по 64 прогона в каждую сторону, шум фазоров после демодуляции 0,3, 1 и 3 мА.

## Результаты

На контрольной сетке средний расчётный момент составил 0,814 Н·м для стержней и 0,805 Н·м для раскрытий. В таблице число принятых оценок с верным знаком из 128. P95 абсолютной ошибки в об/мин указан после разделителя для групп с достаточным числом принятых оценок. Редкие уверенные оценки раскрытий при 3 мА могли сильно ошибаться по скорости.

Преимущество стержней по доле верных оценок сохраняется как в предварительном прогоне с меньшим рангом и тремя сечениями скоса, так и в уточнённом прогоне.

## Проверка разрешения

На участке 12 периодов ШИМ среднеквадратичное расхождение пробного тока между полным нелинейным FEM и проекцией составило 0,166 мА для стержней и 0,037 мА для раскрытий. Повышение разрешения прямого интегрирования в три раза изменило пробный ток на 0,028 и 0,050 мА соответственно. Переход от пяти сечений скоса к девяти на контрольном угле изменил демодулированный ответ на 0,282 и 0,568 мА/В соответственно. В отдельной проверке двух положений без скоса переход от ранга 40 к 52 изменил ответ на 0,44–0,82 мА/В у стержней и около 0,01 мА/В у раскрытий. Различия подходов к дискретизации заметны на шкале шума 0,3 мА. Значения P95 характеризуют проведённую симуляцию с указанным разрешением.

## Воспроизведение

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
$pwmStudy = 'C:/mic_air56_marker_results/pwm_loaded_18_reproduction'
$priorFEM = 'C:/mic_air56_marker_results/loaded_contrast_18_phase_fem'
python tools/run_air56_pwm_comparison.py maps --profile bar_width --prior-dir $priorFEM --out "$pwmStudy/bar_width"
python tools/run_air56_pwm_comparison.py maps --profile modulated --prior-dir $priorFEM --out "$pwmStudy/modulated"
python tools/run_air56_pwm_comparison.py score --maps "$pwmStudy/bar_width" "$pwmStudy/modulated" --out "$pwmStudy/comparison"
```

Проверены 3 840 парных сценариев. Сохранены угловые карты, рабочие точки и короткие записи отдельных фронтов вместе с прямыми FEM-токами. Стенд и прошивка не использовались.
