# Угол неподвижного ротора АИР56 по токам статора

## Опубликованный метод и наша постановка

Schepe, Himker, Mertens и Ponick ввели роторную анизотропию модуляцией раскрытий пазов. Их наблюдатель использует прямоугольную пробу и разность наклонов тока на активных и пассивных интервалах ШИМ. В невязку по приращению потокосцепления входит поправка на насыщение. В эксперименте с заданием нулевой скорости и номинальным моментом после включения поправки ошибка угла оставалась в пределах ±6°. [Статья, раздел 4 и рис. 12](https://doi.org/10.1007/s00502-025-01314-4).

Предыдущая модель АИР56 уже использовала ту же физику, фазозависимый отклик обмоток и угловые шаблоны. В [оценщике скорости и покоя](air56_near_zero.md) угловые гипотезы суммировались, поэтому выходом служили скорость и класс движения. В этом опыте оценщик выдаёт непосредственно механический угол относительно оси заложенной в модель анизотропии. При `cos(2θ)` раскладка стержней или раскрытий повторяется после 180° поворота. Поэтому при холодном определении начального положения остаются два одинаково допустимых положения на оборот.

В FEM рассчитаны два ротора 24/18, со стержнями переменной ширины и с переменными раскрытиями. Каждый рассчитан без скоса и с одним шагом скоса (20°), при прежней нагруженной рабочей точке около 0,8 Н·м. Прямоугольная проба 100 Гц подаётся по α и β отдельными прогонами. Её пиковое напряжение π/4 В даёт первую гармонику с пиком 1 В. Используются средние токи периодов ШИМ и их синхронная демодуляция. При прямоугольной пробе каждый фазор извлекается из той же токовой записи, в которой подана проба. Для сравнения сохранён прежний синусоидальный расчёт с вычитанием отдельного прогона фона.

Упрощённый перенос опубликованной схемы проверен на основной угловой гармонике. В одном варианте к ней добавляется оценка отклика, привязанного к фазе рабочего поля. Расширенный вариант сопоставляет комплексный измеренный ток с FEM-откликом по шести фазам рабочего поля и всем калибровочным углам. Он учитывает изменение сигнатуры ротора с самой фазой поля. Непосредственная обработка наклонов тока внутри импульса и замкнутый регулятор из статьи в этот опыт не входят.

## Результат

Калибровка выполнена на 24 углах сетки уровня 4. Проверочный ток получен интерполяцией другой сетки уровня 6 с 24 углами, сдвинутыми на 3,75°. Для каждого случая использованы 512 общих случайных углов и одинаковые реализации добавленного шума. На компоненты демодулированного сигнала наложен белый шум 0,3, 1 и 3 мА и постоянное в течение прогона смещение с СКО 0,1 мА. Это шумовая модель фазоров, её связь с шумом и частотой выборок АЦП пока не калибрована. Времена заданы на одну ось. При последовательных пробах время обработки двух осей как минимум вдвое больше, без учёта установления.

Ниже P95 абсолютной ошибки механического угла на неподвижном роторе, по модулю 180°. Прямоугольная проба, 0,2 с обработки на ось, все шесть фаз рабочего поля.

| Ротор и скос | 0,3 мА | 1 мА | 3 мА |
|---|---:|---:|---:|
| Стержни, 0 шагов | 2,57° | 3,30° | 6,71° |
| Стержни, 1 шаг | 1,70° | 2,29° | 5,52° |
| Раскрытия, 0 шагов | 19,47° | 39,04° | 76,83° |
| Раскрытия, 1 шаг | 62,17° | 82,39° | 84,34° |

У стержней при 3 мА и 0,2 с на ось P95 модели основной гармоники составлял 12,09° без скоса и 8,90° со скосом. При 0,6 с на ось P95 фазозависимой модели составил 4,42° и 3,10°. На одной фазе рабочего поля при 0,3 мА учёт фиксированной для этой фазы составляющей уменьшил P95 с 67,07° до 27,06° и с 68,57° до 25,69°. При равномерном объединении всех шести фаз эта простая поправка сокращается в невязке и результат совпадает с основной гармоникой. Снижение ошибки даёт учёт изменения всей угловой сигнатуры по фазе поля. У варианта с раскрытиями полная карта иногда ухудшает оценку относительно основной гармоники. Эти числа относятся к конкретным геометриям, рабочей точке и пробе АИР56. При отдельной проверке на 24 фактических узлах контрольной сетки без добавленного шума P95 у стержней составил 2,07° и 1,32°.

Опыт оценивает угол после установления возбуждения при заданных нулевых оборотах. Из измерения угла с такой погрешностью нельзя автоматически вывести быструю идентификацию знака на ±0,1 об/мин. На этой скорости за 0,4 с вал проходит всего 0,24°. Механический пуск привода, траектории с новым наблюдателем и удержание момента в замкнутом контуре здесь не моделировались. Стенд не использовался.

## Воспроизведение

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
$angleStudy = 'C:/mic_air56_marker_results/standstill_angle_18_reproduction'
$loaded = 'C:/mic_air56_marker_results/loaded_contrast_18_phase_fem'
$sine = 'C:/mic_air56_marker_results/moving_pwm_18_refined'
foreach ($rotor in 'bar_width', 'modulated') {
    python tools/run_air56_standstill_angle.py square --profile $rotor --loaded-dir $loaded --out "$angleStudy/square/$rotor"
}
python tools/run_air56_standstill_angle.py score --sine-dir $sine --square-dir "$angleStudy/square" --out "$angleStudy/comparison"
```
