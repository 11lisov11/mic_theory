# АИР56. Пуск под нагрузкой и чтение угла по токам

Продолжение исследования проверяет причину расхождения момента после подхвата и управление на независимо уточнённом шаге поля. [Момент по периодам ШИМ и обратная связь](air56_pwm_torque_transfer_ru.md).

В этом опыте на свободный вал 18-пазового ротора с двумя пассивными вставками действует внешний момент уже при первом включении ключей. Это модель отпускания вала из покоя под нагрузкой. В первые 11 мс обмотки используются для определения положения. Затем тот же инвертор подхватывает вал и ведёт его по заданию. Модель вращения включает инерцию и вязкое трение. Статический момент трения, люфт, мёртвое время силовых ключей и реальные переходные характеристики АЦП в эти расчёты не входят.

## Удержание и реверс при моменте с первого импульса

В четырёх замкнутых прогонах по 12,5 с начальный угол был неизвестен регулятору. На первом разбиении задачу начального угла и нагрузки решала FEM. На втором разбиении функция C с двумя пространственными калибровками выбирала профиль по записи токов. Для этой серии взята исходная версия таблицы C. Динамика объекта и выбранной модели в каждой паре использует одинаковый шаг интегрирования. Независимая проверка переноса на другой шаг описана ниже.

| Захват, скос | Вперёд, вал / по токам, об/мин | Назад, вал / по токам, об/мин | Размах удержания | P95 ошибки чтения | P95 ошибки слежения |
|---|---:|---:|---:|---:|---:|
| FEM, без скоса | +0,0984 / +0,0985 | −0,1007 / −0,1003 | 0,591° | 0,046° | 0,227° |
| FEM, один шаг | +0,1021 / +0,1005 | −0,1005 / −0,1000 | 0,193° | 0,081° | 0,166° |
| C, без скоса | +0,1012 / +0,1007 | −0,1023 / −0,1023 | 0,839° | 0,054° | 0,267° |
| C, один шаг | +0,0983 / +0,0984 | −0,1016 / −0,1008 | 0,648° | 0,067° | 0,178° |

В основной паре опытов угол по токам подтвердил смену направления через 0,95 с без скоса и 0,91 с со скосом после перехода задания через ноль. Оценка использовала предшествующую секунду и требовала сохранения обратного направления в течение 0,30 с. Знак во всех проверенных секундных окнах установившихся участков совпал с заданием в обоих основных прогонах. ## Эксперимент

В основной паре начальный механический угол 27°, первое задание 35°, внешний момент +0,020 Н·м. Положение, скорость и момент объекта доступны только регистратору. Начальная скорость задана нулевой. Отсчёт времени пуска начинается одновременно с отпусканием вала и первым импульсом. Сначала подаются 12 импульсов по 0,25 мс с номинальным вектором напряжения 82 В. Ещё восемь импульсов по 1 мс с номиналом 35 В разрешают неоднозначность на 180°. Двухуровневый идеальный инвертор с шиной 310 В переключается с первого импульса. На границах состояний записываются две компоненты тока штатных обмоток. Пусковая подпись содержит 168 скалярных отсчётов. К каждому добавлен независимый шум с RMS 3 мА.

Наблюдатель подбирает начальный механический угол и постоянный на этих 11 мс момент возмущения по рассогласованию измеренных и рассчитанных токов. Априорная оценка момента имеет среднее ноль и стандартное отклонение 0,050 Н·м для любого знака нагрузки. Вычисляются обе полярности, а в рабочее наблюдение передаются выбранное состояние поля, скорость, угол и неопределённость оценки. В двух отдельных контрольных пусках момент в алгоритме распознавания оставлен нулевым для сравнения при одинаковой записи токов.

После захвата нагрузка сохраняет знак через реверс. Траектория, токовый тракт и критерии скорости и угла повторяют предыдущий эксперимент с ШИМ 250 Гц. В зачёт идут фактическое движение свободного вала и оценка из токов. Среднюю скорость считаем в каждом установившемся окне длиной около 3,53 с, размах удержания — за последние 2,55 с. Учитываются углы и внутри периода ШИМ на границах переключений. [Предыдущий эксперимент и критерии](air56_terminal_servo_ru.md).

## Что видно в первые 11 мс

При +0,020 Н·м смещение к концу импульсов составило −0,294° без скоса и −0,560° со скосом. При прежнем предположении о нулевом пусковом моменте ошибки чтения угла были +0,271° и +0,269°, ошибки скорости +12,00 и +12,13 об/мин. Совместная оценка дала ошибки угла −0,084° на обоих роторах, ошибки скорости −3,04 и −1,74 об/мин. Оценки начального возмущения составили +0,0251 и +0,0229 Н·м. Эти числа характеризуют качество запуска наблюдателя. Электромагнитные импульсы и внешний момент действительно успевают сдвинуть вал.

Совместная оценка проверена также при углах 83°, 207°, 311° и при моменте обратного знака. В коротких опытах проверяется захват к концу 11 мс. При несовпадающих сетках объекта и наблюдателя проверены остаточное рассогласование тока и разница между двумя гипотезами полярности. Для допуска к замыканию контура требуется, чтобы нормированный квадрат рассогласования укладывался в 99,9%-й квантиль χ² при 167 степенях свободы, а разница стоимости противоположных гипотез превышала 2 ln(1000). Порог рассчитан для принятой модели независимого шума. При недостоверном захвате симуляция заканчивается после пробных импульсов, число выданных команд регулятора равно нулю.

## Быстрое определение положения

Для чтения без решения FEM в момент захвата подготовлены таблицы откликов обмоток при двух калибровках двигателя. Каждая таблица получена из переходной FEM со свободной механикой при моментах ±0,030 Н·м. Для проверки используются другие начальные углы и моменты ±0,020 Н·м. Механический угол и профиль объекта в аргументы функции чтения не входят.

Код на C проецирует записанные фазные токи на базис, вычисленный по калибровочным данным, и ищет согласованные угол и нагрузку. Для каждого кандидата момент оценивается аналитически. Угловой поиск уточняется кубической интерполяцией. Функция возвращает угол в конце измерения, скорость, оценку момента, выбранную калибровку и меру рассогласования с токами. В неё входят также составляющие измерения, отброшенные при сжатии. Для использования функции нужны заголовок, двоичная таблица для заданного скоса и размеры массивов из соседнего файла JSON. В этой работе функция выполнялась на ПК. Основной динамический регулятор по-прежнему использует FEM. [Функция C](../research/air56_rotor_fingerprinting/capture_lookup.c) · [Экспорт таблиц и независимая проверка](../research/air56_rotor_fingerprinting/preloaded_native.py).

В предварительном опыте одна таблица с шагом 2,5° при шуме 3 мА дала P95 ошибки угла 0,83° без скоса и 0,55° со скосом на той же пространственной дискретизации. При переносе на вторую сетку та же таблица выбрала положение с ошибкой свыше 90° в 45 и 72 из 192 записей соответственно. Поэтому итоговая функция хранит две калибровки с шагом 1,25° и сравнивает их по измеренным токам. Профиль также определяет пространственную модель наблюдателя при включении регулятора.

Итоговые углы отделены от калибровочной сетки и от предварительного опыта. Выбрано по одному случайному углу внутри каждого из 24 секторов по 15°. На каждом угле рассчитаны оба знака нагрузки, по четыре реализации шума при 0,3, 1 и 3 мА. Таким образом, в каждой строке по скосу, модели и шуму лежат 48 разных физических пусков и 192 шумовые записи. Знак нагрузки, угол и номер сетки используются только при оценке результата. Для независимой проверки по времени электрический шаг разбит пополам, механический момент интегрируется трапецией, физические моменты измерения токов прежние. Этого варианта интегратора в таблицах нет.

Для таблицы введена поправка на интерполяцию. На 48 предварительных пусках каждого профиля при известном угле и моменте определялось наибольшее среднеквадратичное расхождение предсказанной и рассчитанной записи тока. Перед допуском к управлению оно добавляется к шумовому порогу по норме, а требуемое разделение гипотез полярности увеличивается с учётом этого расхождения. Параметры сохранены в JSON рядом с двоичными таблицами. Решение о допуске на итоговых углах использует только текущую запись токов.

## Угол при независимом уточнении времени в объекте

Базовая таблица из двух калибровок успешно прочитала все итоговые пуски на обеих пространственных сетках при исходном интеграторе. При 3 мА наихудшая ошибка среди них составила 0,621°. Но при двух электрических подшагах и трапецеидальном интегрировании механики она отклонила все пуски на обоих скосах. До проверки качества у ротора со скосом пять из 192 ответов при 3 мА оказались в неправильном полупериоде. По сравнению с измерением ошибка численного решения меняется согласованно сразу в нескольких участках одного пакета ШИМ.

Для следующей версии использованы 48 пар предварительных записей при одном и двух подшагах. Из разностей токов выделены восемь главных направлений. Они исключены и из углового поиска, и из проверки остаточного рассогласования. Угол, скорость и момент испытательного объекта в эту операцию не подаются. Моменты измерения токов и все 20 импульсов остались прежними. При настройке допуска расхождения по очереди исключались целые группы углов. Для более мелкой пространственной сетки к бюджету интерполяции добавлен удвоенный максимум полученной таким способом остаточной ошибки уточнения. Это инженерный запас.

После выбора восьми направлений создана отдельная проверка. На **24 новых углах** с обоими знаками нагрузки каждый участок постоянного напряжения объекта разбит **на четыре подшага**. Такие траектории не использовались ни при калибровке таблиц, ни при выборе направлений. При каждом уровне шума и каждом скосе получено 192 шумовые записи с 48 разных механических пусков. Приняты все записи. Наибольшая ошибка угла за все три уровня шума в этом опыте составила 0,715°.

| Шум | P95 угла без скоса | Максимум без скоса | P95 угла со скосом | Максимум со скосом |
|---|---:|---:|---:|---:|
| 0,3 мА | 0,357° | 0,629° | 0,416° | 0,591° |
| 1 мА | 0,367° | 0,661° | 0,425° | 0,604° |
| 3 мА | 0,432° | 0,715° | 0,481° | 0,635° |

Медианное время одного вызова функции на ПК, вместе с переходом из Python в C, составило при 3 мА 0,158 и 0,141 мс соответственно. Сбор пусковой записи занимает отдельно 11 мс. Таблицы занимают 395 424 байта без скоса и 347 904 байта со скосом. Измерено время чтения угла по уже собранной записи. Время дальнейшего расчёта FEM-регулятора существенно больше.

Из одиночной записи хуже определяются скорость и момент. При 3 мА на независимом четырёхподшаговом объекте ошибка скорости к концу импульсов имела RMS 8,2 и 10,0 об/мин. Знак пускового возмущения определён правильно в 92,7% и 85,4% записей. Поэтому точность начального угла и возможность регулировать ±0,1 об/мин проверяются разными опытами. ## Передача управления на независимо уточнённый объект

В отдельной серии геометрия объекта имела 2173 свободных узла на сечение, а каждая выдержка ШИМ делилась на четыре части. Быстрый считыватель с исключением восьми составляющих выбрал пространственную калибровку по токам. После этого регулятор получил задание перейти с 27° на 35° и держать угол под 0,020 Н·м. Сравнивались три конфигурации динамического наблюдателя. Погрешность токовой модели в таблице входит только в ковариацию измерения наблюдателя. Во всех случаях шум фактического АЦП — 3 мА на преобразование. Считывание учитывает положение каждого преобразования внутри рассчитанного участка ШИМ.

| Подшаги наблюдателя | Допуск модели тока RMS | Максимальное отклонение вала от 35°, без скоса / со скосом | Максимальная ошибка чтения, без скоса / со скосом |
|---:|---:|---:|---:|
| 1 | 0 мА | 50,22° / 11,70° | 67,84° / 12,52° |
| 2 | 4 мА | 2,35° / 8,61° | 0,89° / 7,73° |
| 8 | 3 мА | 2,85° / 2,69° | 1,03° / 1,77° |

Числа относятся к интервалу 0,55–0,80 с после захвата. Все шесть записей завершены. При восьми подшагах сбой гораздо меньше, но на обоих роторах вал вышел за допуск 1°. Одновременно менялись шаг наблюдателя и его допуск ошибки тока, поэтому по этим записям нельзя приписать всё улучшение одному параметру. Пусковой считыватель сохраняет точность на независимо уточнённой модели. Для непрерывной обратной связи расхождение токовых переходных процессов после включения регулятора остаётся существенным. [Пусковые записи и результаты подхвата](../research/air56_rotor_fingerprinting/reference/preloaded_start/capture_cases.csv).

В интервале 0,55–0,80 с при восьми подшагах средний момент поля был близок к приложенным 20 мН·м. Без скоса он составил 20,8 мН·м, со скосом — 19,2 мН·м. При этом среднеквадратичная разность между моментом наблюдателя и моментом поля объекта по периодам ШИМ достигала 39,1 и 12,3 мН·м. Размах движения вала за тот же интервал составил 4,81° и 5,16°. Поэтому для удержания важно проверить воспроизведение момента внутри движения даже при верном среднем моменте. В опыте с одним подшагом без скоса оценка внешней нагрузки к 0,8 с достигла 3,389 Н·м при фактических 0,020 Н·м. Ошибка пускового угла сама по себе такого срыва не объясняет.

## Воспроизведение

Из корня репозитория можно повторить отдельно замкнутый прогон с нагрузкой от первого импульса. Аргумент `--skew 0` выбирает прямой ротор. В приведённом примере вторая команда заново рассчитывает данные для таблиц, экспортирует их и выполняет слепую проверку функции C. Третья команда использует сохранённую калибровку и воспроизводит полную траекторию со считывателем C на второй сетке. Требуются зависимости проекта и компилятор GCC. [Конфигурации опытов](../research/air56_rotor_fingerprinting/reference/preloaded_start/cases.json).

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
python research/air56_rotor_fingerprinting/terminal_servo.py --case preloaded_pwm --skew 1 --out C:/mic_air56_preload_replay
python research/air56_rotor_fingerprinting/preloaded_map.py --full --workers 4 --out C:/mic_air56_preload_replay
python research/air56_rotor_fingerprinting/preloaded_report.py --replay bank_fine1 --out C:/mic_air56_native_replay
```
