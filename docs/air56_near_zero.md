# Покой, трогание и реверс АИР56В2 в модели считывания по обмоткам

## FEM-отклик и шум

Использован 18-пазовый ротор с переменной шириной стержней из [сравнения с движущейся сеткой](air56_moving_pwm.md). Сохранены рабочая точка около 0,8 Н·м, нелинейная характеристика стали, проба 100 Гц и 1 В, ШИМ 16 кГц и мёртвое время 1,35 мкс. Рассчитаны нулевой скос и скос на один роторный шаг. Для каждого из семи режимов 0, ±0,1, ±0,2 и ±0,5 об/мин построены токовые ответы из переходных FEM-прогонов с меняющимся углом. В каждом режиме 24 угла на полуобороте. Калибровочная карта берётся из предшествующего расчёта неподвижного ротора на другой сетке. Фазорный шум после демодуляции составляет 0,3, 1 или 3 мА, постоянное смещение внутри записи 0,1 мА.

Для заданных переходов механический угол интегрируется по линейной рампе. Пробный ток интерполируется по углу и знаковой скорости из независимых FEM-карт. Дополнительно для обоих скосов выполнены цельные переходные ШИМ-записи 7,2 с с меняющейся скоростью, от покоя до +0,5 и от +0,5 до −0,5 об/мин, с отдельным расчётом фона и каждой оси пробы. Они проверяют согласие интерполяции с непрерывным распространением электромагнитного состояния. Задержки и статистика начальных углов оценены по банку фазоров. Угол, величина скорости, момент трогания и перехода через ноль используются как эталон генерации и проверки. Наблюдателю известна электрическая фаза возбуждения.

## Наблюдатель

Из фазоров формируются симметричные бесследовые токовые признаки. Пары α/β группируются по трём фазам возбуждения и усредняются внутри 0,3 с. Регуляризация постоянного фазового смещения снижает влияние расхождения FEM-карт. Для ускорения расчёта оставлены первые 12 ортонормированных временных компонент. По скользящему окну оцениваются правдоподобия строго нулевой скорости и двух знаков. Для ненулевой скорости применяется сетка от 0,025 до 1,25 об/мин в каждую сторону. Порог выдачи класса 95% и равные априорные веса трёх классов. Остальные решения считаются неопределёнными.

Постоянные скорости проверены в 64 независимых реализациях для каждого знака или покоя при окнах 1,2, 3,6, 7,2, 14,4 и 21,6 с. Для переходов применены окна 3,6, 7,2 и 14,4 с с новым решением каждые 0,6 с. У каждой рампы 32 начальных угла и шумовых реализации на направление. Трогание длится 1,2 с до ±0,1, ±0,2 или ±0,5 об/мин. Реверс между противоположными скоростями той же величины проходит за 2,4 с без выдержки в нуле. Первое подтверждение нового направления требует двух последовательных совпадающих оценок после начала движения или после нуля. Для реверса дополнительно отмечается, был ли до начала рампы подтверждён старый знак. Медиана и P95 задержки считаются среди пойманных событий. Сохранение старого знака после нуля учитывается отдельно.

## Покой и постоянная скорость

В каждой ячейке результаты без скоса и со скосом на один шаг. Для покоя числитель показывает подтверждённый ноль из 64, для движения подтверждение правильного знака из 128. Окна выбраны из прогонов, чтобы показать влияние роста шума.

| Шум | Окно | Покой, из 64 | ±0,1, из 128 | ±0,2, из 128 | ±0,5, из 128 |
|---:|---:|---:|---:|---:|---:|
| 0,3 мА | 3,6 с | 58 / 56 | 105 / 128 | 127 / 128 | 128 / 128 |
| 0,3 мА | 7,2 с | 64 / 64 | 126 / 128 | 125 / 128 | 128 / 128 |
| 1 мА | 14,4 с | 64 / 64 | 128 / 128 | 128 / 128 | 128 / 128 |
| 3 мА | 3,6 с | 0 / 0 | 2 / 2 | 16 / 21 | 99 / 116 |
| 3 мА | 14,4 с | 57 / 56 | 114 / 127 | 128 / 128 | 128 / 128 |
| 3 мА | 21,6 с | 63 / 62 | 128 / 128 | 128 / 128 | 128 / 128 |

При 3 мА в окне 3,6 с все 64 прогона покоя на каждый скос остались неопределёнными. Ложного движения в этом окне не было. На ±0,1 об/мин подтверждения ошибочного покоя при 3 мА наблюдались в отдельных прогонах окон 7,2 и 14,4 с. При 0,3 мА без скоса отмечены отдельные ошибки знака на ±0,1 и ±0,2 об/мин, в том числе при длинных окнах. Полные распределения покоя, движения, отказов и скорости находятся в CSV.

## Трогание и реверс

При 0,3 мА в окне 3,6 с подтверждение нового знака было в 64/64 прогонах каждого перехода при обоих скосах. Медиана задержки от начала трогания составила 3,0 с до ±0,1, 2,4 с до ±0,2 и 1,8 с до ±0,5 об/мин. После пересечения нуля медиана подтверждения нового знака составила 3,0 с на всех трёх скоростях. На ±0,1 об/мин P95 задержки реверса составил 9,0 с без скоса и 3,6 с со скосом. Медиана последней выдачи прежнего знака после нуля составила 0,9–1,2 с среди прогонов, в которых прежний знак сохранялся.

При 1 мА и окне 7,2 с все переходы дали по 64/64 подтверждений нового знака и исходного состояния. На ±0,1 об/мин медиана составила 4,8 с для трогания и 5,4 с для реверса при обоих скосах.

При 3 мА окно 7,2 с подтвердило оба знака во всех 64 реверсах между ±0,2 и между ±0,5 об/мин при обоих скосах. Медиана задержки составила 6,0–6,3 с на ±0,2 и 5,4 с на ±0,5. При ±0,1 об/мин старый и новый знаки подтвердились в 36/64 без скоса и в 35/64 со скосом. Увеличение окна до 14,4 с подняло эти числа до 57/64 и 62/64. Медиана задержки нового знака в последнем режиме составила 10,2 и 10,8 с. Трогание до ±0,1 при 3 мА в том же окне дало новый знак в 62/64 и 64/64, медиана 8,4 с. Уверенный исходный покой в этих записях был у 44/64 и 54/64 соответственно.

В непрерывных ШИМ-прогонах от покоя до +0,5 и от +0,5 до −0,5 об/мин среднеквадратичное расхождение с интерполированным банком на проверенных отметках составило 0,10–1,29 мА/В по обоим скосам. Поэтому задержки характеризуют наблюдатель в сценарной симуляции. Модель использует предписанную скорость, заданную рабочую фазу и шум после демодуляции. Самостоятельный пуск под нагрузкой и работа замкнутого регулятора в эту проверку не входили.

## Воспроизведение

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
$zeroStudy = 'C:/mic_air56_marker_results/near_zero_18_reproduction'
$loadedFEM = 'C:/mic_air56_marker_results/loaded_contrast_18_phase_fem'
$calibration = 'C:/mic_air56_marker_results/moving_pwm_18_refined/bar_width'
python tools/run_air56_near_zero.py maps --skew 0 --loaded-dir $loadedFEM --out "$zeroStudy/skew_0"
python tools/run_air56_near_zero.py maps --skew 1 --loaded-dir $loadedFEM --out "$zeroStudy/skew_1"
python tools/run_air56_near_zero.py score --banks "$zeroStudy/skew_0" "$zeroStudy/skew_1" --calibration $calibration --out "$zeroStudy/comparison"
python tools/run_air56_near_zero.py check-ramps --bank "$zeroStudy/skew_0" --loaded-dir $loadedFEM --out "$zeroStudy/check_0"
python tools/run_air56_near_zero.py check-ramps --bank "$zeroStudy/skew_1" --loaded-dir $loadedFEM --out "$zeroStudy/check_1"
```

Сохранены 13 440 испытаний постоянной скорости, 6 912 испытаний переходов и четыре непрерывные контрольные записи ШИМ. Стенд и прошивка не использовались.
