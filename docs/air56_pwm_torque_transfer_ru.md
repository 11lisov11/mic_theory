## Условия

Объект — свободный 18-пазовый ротор с переменной шириной стержней и двумя пассивными магнитными вставками. В модели коэффициент модуляции ширины стержней равен 0,6. Две диаметрально расположенные вставки занимают по 16° в наружном слое ротора глубиной 0,5 мм, остаточная индукция материала 0,4 Тл. Состояние поля, угол, скорость и нагрузка объекта доступны регистратору. На входах контроллера — шумные токи штатных обмоток в двух неподвижных осях и его собственная последовательность переключений. Начальный механический угол 27° скрыт. Покой до первого импульса известен. Цель подхвата — 35°. Постоянный внешний момент +0,020 Н·м приложен с первого импульса и сохраняет знак при реверсе. Проверяются прямой ротор и скос в один пазовый шаг, представленный тремя осевыми сечениями.

Использована та же переходная нелинейная FEM на 2173 свободных узлах в сечении с движущейся границей в зазоре, инерцией и вязким трением. Инвертор двухуровневый, шина 310 В, пять выдержек в периоде в общем случае, ШИМ 250 Гц. До 32 преобразований тока на конце выдержки, через 2 мкс, шум одного преобразования 3 мА RMS, доля коррелированной дисперсии 0,03. Во время 11 мс пускового опроса используются 168 скалярных отсчётов. Угол первоначально разрешает прежний C-считыватель. Границы применимости задают модель вязкого трения, идеальные ключи и принятая модель АЦП. Сухое трение, люфт, мёртвое время и конечная полоса аналогового тракта в расчёт не вошли. [Условия предыдущей серии](air56_preloaded_start_ru.md).

## Разделение причин

Для проверки одного периода восстановлены команды ключей двух прежних неудачных прогонов при восьми подшагах наблюдателя. Механика и поле объекта заново рассчитаны от отпускания вала. В диагностике начала отдельных периодов копируются в отдельную расчётную модель. До конца такого периода все варианты получают одинаковые длительности и напряжения, измеренные токи не подаются. Таким образом измеряется ошибка прогноза при заведомо одинаковом начальном поле, положении и скорости. Это отдельный диагностический опыт. В замкнутом управлении такого копирования нет.

Контур сравнивает средний за 4 мс электромагнитный момент. В расчёте он равен сумме импульсов на внутренних интервалах, делённой на период ШИМ. Для каждого интервала импульс равен его длительности, умноженной на полусумму двух граничных значений момента.

Электрическая часть использует неявный Эйлер. Длительность шага меняет затухание вихревых токов в клетке и ход фазного тока внутри выдержки. На дискретной траектории механика интегрирует момент по трапеции. Ошибка напряженческого прогноза тока проецировалась фильтром на угол, скорость и внешнюю нагрузку. Особенно опасна ситуация, когда фильтр пытается объяснить изменение формы тока изменением нагрузки. Отдельно проверялся конечный момент при среднем напряжении за период. Он характеризует другой режим возбуждения и может расходиться со средним по пяти реальным выдержкам даже при верном начальном состоянии.

Восстановлены все 200 исходных периодов каждого отказа. На 20 периодах каждого скоса выполнены прогнозы из общего состояния. При восьми подшагах вместо четырёх RMS ошибки среднего момента за период составила 6,99 мН·м без скоса и 3,22 мН·м со скосом. Подстановка конечного момента при среднем напряжении вместо среднего момента переключаемого поля дала RMS 33,77 и 16,96 мН·м на этих же периодах. При сравнении переключаемых моделей основная ошибка набегала во время длинных выдержек нулевого вектора. На этих выдержках токи в обмотках и клетке продолжают течь и создавать момент. При малом управляющем напряжении на них приходится большая часть периода. Вклад этих выдержек в пересчёте на полный период имел RMS 7,03 и 3,22 мН·м, вклад активных векторов — 0,49 и 0,06 мН·м. Вклады по знаку могут частично компенсироваться. Соответствующие ошибки конечного вектора фазного тока имели RMS 32,2 мА без скоса и 24,6 мА со скосом. [Диагностика программой воспроизведения](../research/air56_rotor_fingerprinting/pwm_torque_diagnostic.py).

Для отделения электрической причины на тех же периодах временно фиксировался угол в обеих копиях машины. Расчёты с четырьмя и восемью подшагами начинали с одинакового поля. Сначала момент уточнённого поля интегрировался по четырём прежним интервалам. Затем тот же момент интегрировался по всем восьми. Первая разность выделяет изменение поля при общем правиле интегрирования момента. Вторая выделяет изменение самой квадратуры. Для каждого периода их знаковая сумма точно равна общей разности. RMS в таблице рассчитаны отдельно.

| При неподвижной геометрии, RMS | Без скоса | Один шаг |
|---|---:|---:|
| Полное расхождение момента за период | 6,27 мН·м | 3,35 мН·м |
| Изменение рассчитанного поля | 4,42 мН·м | 2,42 мН·м |
| Изменение квадратуры момента | 1,95 мН·м | 0,94 мН·м |
| Разность конечного вектора тока | 31,9 мА | 24,2 мА |

Наконец, в отдельной диагностике известную дискретизацию объекта подставили в интерполяцию трёх прогнозов. Из общего начального состояния RMS ошибки среднего момента снизилась до 0,070 и 0,0085 мН·м. Это оценка точности самой интерполяции. В замкнутом испытании её параметр приходится восстанавливать по токам.

В замкнутом контуре регистрируется момент, предсказанный перед каждой выдержкой. К этому моменту наблюдатель уже видел токи предыдущих выдержек того же периода. В отдельном опыте с общим начальным состоянием момент всего периода прогнозируется заранее, до любого нового отсчёта тока.

## Изменение наблюдателя

Наблюдатель рассчитывает три отклика одной выдержки при одном, трёх и семи электрических подшагах. Состояния поля, токов, вала и средний момент интерполируются по величине, обратной числу подшагов. Это аппроксимация ошибки дискретизации слагаемыми первого и второго порядка. Время преобразований АЦП учитывается на каждом из трёх откликов. Для оценки положения и нагрузки начальная калибровка ищет по пусковой записи также параметр интерполяции. В динамическом варианте этот параметр — дополнительное состояние наблюдателя. Производная прогноза по этому параметру вычисляется из трёх расчётных откликов. Поправка определяется по двум измеренным компонентам тока и согласованно изменяет оценку поля и движения. Для переноса ковариации остальных состояний использована касательная центрального расчёта. Истинное число подшагов объекта и зарегистрированный момент поля не входят в интерфейс наблюдателя.

В основной проверке объект делает четыре равных подшага за выдержку. В дополнительной серии число подшагов объекта увеличено до шести, seed шума изменён на 10037. Ни одно из этих значений не используется как узел интерполяции наблюдателя. Пространственная геометрия остаётся в банке ранее известных калибровок и выбирается по токам при подхвате. Таким опытом проверяется перенос между разными интегрированиями поля на калиброванной геометрии. Параметр интерполяции описывает погрешность численной модели. Физический параметр реального двигателя по нему не идентифицирован. [Модель отклика](../fem/air56/dwell_response.py) · [Наблюдатель и регулятор](../tools/run_air56_terminal_servo.py).

11 мс — длительность электрической записи на шкале времени двигателя. После первичного чтения функцией C здесь выполняются дополнительные переходные расчёты при подборе параметров. Динамическая обратная связь также использует FEM. Реализация предназначена для исследования на ПК. Время отдельного вызова прежнего C-считывателя не характеризует вычислительную стоимость этого контура.

На фазе первого удержания средняя оценка нагрузки в этом варианте составила 19,91 и 20,01 мН·м при заданных объекту 20,00 мН·м.

Для полных траекторий после пускового опроса уменьшен вращающийся пробный вектор с 2,5 до 0,6 В и увеличена жёсткость управления с 0,52 до 0,70 Н·м/рад. Состояния силовых ключей по-прежнему задаются шиной 310 В. Начальные импульсы, шум и нагрузка не менялись. Краткие сопоставления способов коррекции оценивались в одном и том же начальном окне. Некоторые вспомогательные запуски были остановлены после сохранения начального окна. Сводная таблица показывает запрошенную и записанную длительности, а также признак оценки полного реверса. Для тех же пусковых импульсов и команд до 0,80 с короткий прогон воспроизводит проверяемое окно.

Проверялся и более дорогой вариант управления. При выборе команды он заранее рассчитывает момент для переключений следующего периода. За 0,55–0,80 с максимальное отклонение составило 0,085° без скоса и 0,100° со скосом, RMS ошибки среднего момента — 0,052 и 0,761 мН·м. Это два коротких опыта по 0,80 с. В итоговых полных реверсах использован обычный регулятор с обновлённым наблюдателем.

## Почему после успешного подхвата можно потерять вал

При переходе с четырёх на шесть подшагов объекта начальный угол удержался при обоих скосах. Затем на роторе со скосом оценка стала расходиться с валом уже в начале движения вперёд. Фильтр оценивал внешнюю нагрузку как практически постоянную. После серии малых невязок тока он также почти перестал допускать ошибку собственного прогноза ускорения. Часть расхождения токов при этом объяснялась поправкой к электрическому отклику. По малой внутренней невязке тока обнаружить уход вала вовремя не удалось.

На четырёх подшагах вариант без дополнительной дисперсии со скосом сохранял правильное прямое движение и потерял вал во время обратного хода. Через 8,964 с после подхвата ошибка чтения впервые превысила 1°. В этот момент сглаженная нормированная невязка составляла 0,49, а коэффициент открытия фильтра нагрузки был меньше 10⁻³⁰. Через 0,112 с ошибка превысила 10°. Средняя фактическая скорость за обратный участок оказалась −0,5128 об/мин при показании −0,0926 об/мин. Этот опыт показывает практическую опасность проверки алгоритма только по показаниям наблюдателя.

В повторном опыте в ковариацию движущегося вала добавлена погрешность электромагнитного момента за один период ШИМ. Для RMS 1,5 мН·м, периода h и инерции J согласованные поправки равны Δω = h × 0,0015 / J и Δθ = h × Δω / 2. Это одна коррелированная составляющая дисперсии угла и скорости. Среднее значение управляющего момента от этого не меняется. При появлении новой информации в токах фильтр сохраняет возможность поправлять движение и после стабилизации оценки внешней нагрузки. Величина 1,5 мН·м выбрана по порядку остаточной ошибки начальной серии. В парном повторе на шести подшагах сохранены реализация шума, команды задания, объект и коэффициенты регулятора. Численные результаты отдельных опытов приведены в таблице полного цикла.

## Оценка траектории

Для движения при ±0,1 об/мин считаются наклоны фактического и считанного по токам угла в установившихся окнах около 3,53 с. Допуск ±0,02 об/мин. Знак дополнительно оценивается по предыдущей секунде. Реверс считается распознанным, когда отрицательная оценка ниже −0,02 об/мин сохраняется 0,30 с. Для начального удержания проверяется окно 0,55–0,80 с, для конечного — последние 2,55 с. Для строгого зачёта максимум проверяется также за всё начальное удержание с 0,55 с до команды движения в 1,00 с и с выхода задания на полный покой в 9,65 с до конца. Конечный размах за 9,95–12,50 с тоже должен укладываться в 1°. Максимум и размах включают границы внутренних шагов FEM. Пуск с 27° на 35° оценивается отдельно от удержания. Длительность полного испытания после пускового опроса 12,5 с. Ни одна частичная запись не засчитывается как прошедший реверс.

Полные исходные массивы NPZ и настройки каждого опыта сохранены локально в `C:/mic_air56_marker_results/pwm_torque_transfer`. В репозитории восемь полных траекторий включают 25 000 записей. SHA-256 для CSV рассчитан с переводами строк LF, для NPZ и рисунков — по исходным байтам. [Контрольные суммы](../research/air56_rotor_fingerprinting/reference/pwm_torque_transfer/manifest.json).

## Воспроизведение

Из корня репозитория. Каталог назначения должен быть новым для выбранного опыта. Банк пусковых откликов копируется из версионированной калибровки, C-считыватель собирается GCC. Каждый опыт использует собственный каталог банка. Для каждой пары сначала рассчитываются оба скоса, затем строится сводка. В примере используются одинаковые настройки наблюдателя для двух временных сеток объекта.

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
$study = 'research/air56_rotor_fingerprinting/pwm_transfer_study.py'
$out = 'C:/mic_air56_transfer_repeat'
foreach ($case in 'torque4_', 'torque6_') {
    foreach ($skew in 0, 1) {
        python $study --case $case --skew $skew --out $out
        if ($LASTEXITCODE) { throw "FEM run failed" }
    }
    python $study --out $out --primary $case
    if ($LASTEXITCODE) { throw "Scoring failed" }
}
```

Для парного опыта без дополнительной дисперсии момента на шести подшагах используется вариант `refined6_`. Для исходной пары на четырёх — `parallel`. Для воспроизведения причинного эксперимента используются прежние записи двух отказов и программа [поинтервального расчёта](../research/air56_rotor_fingerprinting/pwm_torque_diagnostic.py).
