## Что исследовано и получено

На математической модели асинхронного двигателя сопоставлены управление с
постоянными параметрами и параметрическая адаптация наблюдателя и векторного
регулятора. Основное сравнение заранее задано для двух режимов при задании
скорости 150 рад/с: изменения параметров двигателя и совместного действия
параметрических и измерительных возмущений. Для каждого режима использованы
20 одинаковых для сравниваемых алгоритмов реализаций случайных воздействий.

В этих режимах средняя абсолютная погрешность регулирования скорости уменьшилась
на **66–68%**, стандартное отклонение момента — на **32–34%**. Средние максимумы
тока изменились менее чем на 1%; энергия потерь в меди статора увеличилась
примерно на 3%. Полные результаты остальных режимов и алгоритмов сохранены в
исходных данных.

Механизм улучшения связан с уточнением оценки скорости по невязке токов и
использованием оценок сопротивлений и взаимной индуктивности в расчёте
напряжения и составляющих тока регулятора. Коэффициенты регулятора скорости и
ограничения тока и момента в основном сравнении одинаковы. Исследование
выполнено на модели с усреднённым напряжением преобразователя.

клонировании в Windows и Linux.

## Проверка из чистой копии репозитория

Из корня репозитория, Python 3.10 или новее:

```sh
python -m pip install -r paper/tebtrans_2026/reproduction/requirements.txt
python paper/tebtrans_2026/reproduction/verify_results.py
```

Команда проверяет SHA-256, 320 подтверждающих случаев, исходный выбор алгоритмов,
парность условий, повторно вычисляет основные показатели и интервалы,
сопоставляет их с сохранённым анализом и проверяет наличие трёх рисунков в Word.

Короткий повторный расчёт двух сравниваемых алгоритмов для первой сохранённой
реализации совместных возмущений:

```sh
python paper/tebtrans_2026/reproduction/rerun_simulation.py --out paper/tebtrans_2026/runs/smoke
```

Это две полные реализации по 2,5 с с шагом 100 мкс. Полученные показатели
сравниваются с исходными значениями для того же seed. Для всех 320 случаев:

```sh
python paper/tebtrans_2026/reproduction/rerun_simulation.py --full --jobs 4 --out paper/tebtrans_2026/runs/full
```

Новый расчёт выполняет неизменённую функцию исходного эксперимента. Обёртка
задаёт переносимые пути к модели и моторному набору и сохраняет новые результаты
отдельно от исторических данных. Длительность зависит от компьютера. Проверка
текущей публикации записана в [evidence/publish_verification.json](evidence/publish_verification.json).
Проверочный повторный расчёт двух полных реализаций выполнен перед публикацией;
его показатели совпали с исходными при относительном допуске 10⁻⁷.
[Отчёт сопоставления](evidence/simulation_replay.json) содержит исходные и
повторно полученные значения каждого показателя.
