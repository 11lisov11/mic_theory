# Исторические скрипты подготовки статьи

Здесь сохранены точные копии скриптов последней редакции и дополнительного
исследования. Они фиксируют происхождение текста, рисунков и проверок.

- `reader_revision_20261029.py` — текст последней редакции и построение рисунков.
- `reader_revision_20261029_audit.py` — проверка чисел и содержания редакции.
- `reader_rasterize.cjs` — перевод SVG в растровые изображения для Word.
- `rewrite_article.py`, `build_vak.py` — использованные вспомогательные функции
  оформления и библиографии.
- `matched_covariance_study.py` — дополнительное исследование 27 октября.

Эти исторические скрипты используют исходные абсолютные пути Windows,
промежуточные редакции и локальный документ-образец предыдущей статьи.
Документ-образец и черновые версии в данный пакет не включены. Для редактирования
готовой статьи используйте Word, текст рукописи и SVG в соседних каталогах.
Для проверки и повторения математического эксперимента используйте переносимые
команды в [основном README](../README.md#проверка-из-чистой-копии-репозитория).
